# ❤️ Сайт «В моём сердце» (Интерактивная анимация)

Атмосферный веб-проект с кинематографичной анимацией приближения биологического человеческого сердца при скролле и раскрытием фотографии внутри.

## ✨ Особенности:
- **Черный фон** с глубоким градиентом и парящими светящимися искрами (Canvas).
- **Анатомическое сердце**: детализированная 3D-модель / фото сердца с реалистичной биологической текстурой.
- **Интерактивный зум при скролле**: сердце пульсирует, а при прокрутке плавно приближается (в 20+ раз) прямо к желудочку/сердцевине.
- **Раскрытие фотографии**: из глубины сердца появляется нежная фотография в неоновой стеклянной рамке с 3D-параллаксом от курсора/пальца.
- **Звук сердцебиения (Web Audio API)**: реалистичный двойной удар («ту-тук»), который ускоряется по мере погружения в сердце!
- **Автоплей**: кнопка автоматического плавного просмотра анимации.
- **Редактирование текста**: возможность прямо на сайте изменить заголовок и послание через кнопку «Изменить слова».
- **Адаптивность**: отлично выглядит на смартфонах, планшетах и компьютерах.

## 🚀 Как запустить на GitHub Pages за 2 минуты:

1. **Создайте новый репозиторий** на [GitHub](https://github.com/new) (например, `my-heart` или `special-for-you`). Сделайте его **Public** (Публичным).
2. **Загрузите все файлы из архива в корень репозитория**:
   - `index.html`
   - `style.css`
   - `script.js`
   - папку `images/` (с `heart.jpg` и `photo.png`)
   *(Или просто перетащите все эти файлы в окно браузера на GitHub)*
3. **Включите GitHub Pages**:
   - Перейдите в **Settings** (Настройки репозитория) → раздел **Pages** слева.
   - В блоке **Build and deployment** выберите:
     - Branch: `main` (или `master`)
     - Folder: `/ (root)`
   - Нажмите **Save**.
4. Через 30–60 секунд GitHub выдаст вам готовую ссылку на сайт (вида `https://ваш-логин.github.io/имя-репозитория/`).

---

## 🖼 Замена фото или текста:
- Чтобы заменить фото, просто замените файл `images/photo.png` на любую другую фотографию с тем же именем.
- Чтобы изменить текст по умолчанию, откройте `index.html` и отредактируйте строки в блоке `#reveal-content`.
